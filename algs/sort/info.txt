정렬에 대한 remind 시 보면 좋은 코드:
        sort.c          size 기반의 정렬 : quick(int* arr, int sz)
        sortPtr.cpp     pointer 기반(반복자와 비슷)정렬 : quick(int* begin, int* end)


언어별 실행결과: 1억개의 0~10000 랜덤 배열 quick
c,cpp :     3.0 ~ 3.2 초                            포인터, register변수로 극대화
java :      4.3 (전통배열사용)                      ArrayList, Integer 사용시 20초
js :        6.4초                                   v8 엔진이 이렇게 좋을줄은 몰랐음
python:     186초 (천만개도 12초).                  내장기능 sort() 사용시 직접구현한 quickPtr보다 2배는 빠름
sortPtr :   2.7 ~ 2.9초                             모든 정렬 포인터 적용, 컴파일 -O3 으로 최적화. 합병정렬도 4초 극초반, 임계값 도달시 삽입정렬전환
