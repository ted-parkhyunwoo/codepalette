람다를 변수로 저장할 수 있는지?

Java:
    함수 인터페이스(단일 함수만 가지고 있는 인터페이스) 없이는 람다식 사용 불가.
    대신 타입 안정성이 확보되어 함수 체이닝 아주 안정적
CPP:
    auto 나 void* 등으로 함수를 변수화 시킬 수 있으나, 함수형 체이닝에 불편함
    c++20 부터 파이프라인으로 연결할 수 있는것으로 앎. std::views 인가 뭔가...
js, dart:
    const나 Function 타입으로 람다식/함수 자체를 변수로 저장 가능
    함수형 체이닝 사용도 용이
python:
    lambda 혹은 함수를 변수로 저장 가능하지만, 람다는 한줄짜리만 구현 가능. 체이닝 불편

결론:
함수형 프로그래밍의 컴파일 언어는 Java, dart 정도가 용이 하다 생각됨
인터프리터는 js, dart 등이 적절함
