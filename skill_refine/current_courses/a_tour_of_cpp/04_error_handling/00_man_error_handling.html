C++ 오류 처리 방법 정리

C++에서 오류를 처리하는 방법은 여러 가지가 있으며, 상황에 따라 적절한 방식을 선택해야 합니다. 아래는 주요 오류 처리 방법과 관련 기능들을 코드와 함께 설명한 HTML 문서입니다.

1. 예외 던지기 (Exception Throwing)

관련 키워드 및 기능

  • throw: 예외를 던질 때 사용
  • try: 예외 발생 가능 코드 블록
  • catch: 예외를 잡아서 처리
  • 예외 클래스: std::exception, std::runtime_error, std::out_of_range 등

코드 예시


#include <iostream>
#include <stdexcept>

int getElement(int arr[], int size, int index) {
    if (index < 0 || index >= size) {
        throw std::out_of_range("Index out of range!");
    }
    return arr[index];
}

int main() {
    int arr[] = {10, 20, 30};
    try {
        std::cout << getElement(arr, 3, 5) << std::endl;
    } catch (const std::out_of_range& err) {
        std::cerr << "예외 발생: " << err.what() << std::endl;
    }
    return 0;
}

2. 오류 코드 반환 (Error Code Return)

설명

예외 대신 오류 상태를 정수나 enum 값으로 반환하여 흐름을 제어합니다.

코드 예시


#include <iostream>

enum ErrorCode {
    SUCCESS = 0,
    INDEX_OUT_OF_RANGE = 1
};

int getElementSafe(int arr[], int size, int index, int& outVal) {
    if (index < 0 || index >= size) {
        return INDEX_OUT_OF_RANGE;
    }
    outVal = arr[index];
    return SUCCESS;
}

int main() {
    int arr[] = {1, 2, 3};
    int value = 0;
    int result = getElementSafe(arr, 3, 5, value);

    if (result == SUCCESS) {
        std::cout << "값: " << value << std::endl;
    } else {
        std::cerr << "오류: 인덱스가 범위를 벗어났습니다." << std::endl;
    }

    return 0;
}

3. 프로그램 종료 (Program Termination)

관련 함수

  • exit(int): 종료 코드와 함께 종료
  • abort(): 즉시 비정상 종료
  • std::terminate(): 예외를 처리하지 못한 경우 호출됨

코드 예시


#include <iostream>
#include <cstdlib> // exit, abort
#include <stdexcept>

void fatalErrorExit() {
    std::cerr << "치명적 오류 발생, 종료합니다." << std::endl;
    std::exit(1);
}

void fatalErrorAbort() {
    std::cerr << "비정상 강제 종료(abort) 호출" << std::endl;
    std::abort();
}

void willTerminate() {
    throw std::runtime_error("예외 처리하지 않음");
}

int main() {
    try {
        willTerminate();
    } catch (...) {
        std::cerr << "예외 처리됨\n";
        // std::terminate(); // 수동으로 호출할 수도 있음
    }
    return 0;
}

추가 기능 설명

noexcept


void safeFunction() noexcept {
    std::cout << "이 함수는 예외를 던지지 않습니다.\n";
}

- 예외를 던지지 않는 함수임을 명시
- 만약 예외가 발생하면 std::terminate()가 호출됨

assert()


#include <cassert>

void divide(int a, int b) {
    assert(b != 0);
    std::cout << "결과: " << a / b << std::endl;
}

- 런타임에 조건을 검사
- 디버그 빌드에서만 유효하며, 실패 시 프로그램 종료

static_assert()


static_assert(sizeof(int) == 4, "int는 4바이트여야 합니다");

- 컴파일 타임 조건 검사
- 주로 템플릿, 타입 검사 시 유용

요약

방법 설명 장점 단점
예외 던지기 throw, try, catch 사용 명확하고 구조적인 처리 가능 오버헤드 및 복잡도 증가
오류 코드 반환 오류 상태를 반환값으로 전달 성능 우수, 단순한 로직 처리 오류 처리 누락 위험
프로그램 종료 exit(), abort(), terminate() 사용 치명적 오류에 단순하고 명확 복구 불가능, 디버깅 어려움

각 방식은 상황에 따라 적절히 선택해야 하며, 특히 라이브러리나 API 설계 시 어떤 방식으로 오류를 처리할지 일관된 정책이 중요합니다.
